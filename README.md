# PostBook

**PostBook** is a mini social media web app that allows users to create, view, update, and delete text posts with image uploads. It uses a Node.js/Express backend, Cloudinary for image storage, MongoDB for the database, and a simple HTML/CSS/JavaScript frontend.

## Features

- Add posts with text and multiple images
- View all posts by a specific user
- Edit or delete existing posts
- Images stored in Cloudinary
- Fully functional API + clean frontend

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript (Vanilla)
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose)
- **Image Upload**: Cloudinary + Multer
